## Release focus

T‑PHANTOM OS 5.3 is a Saudi-developed, security-focused Linux distribution built for practical cybersecurity and digital-investigation workflows, including:

- DFIR and digital forensics
- incident response
- authorized penetration testing
- reverse engineering
- network analysis
- security research and controlled training environments
- bilingual Arabic/English operation

## Validated release areas

The current 5.3 validation includes:

- operating-system identity and desktop integration
- Arabic and English locale availability
- KDE Plasma environment
- boot and installer workflow checks
- VM execution on the current build
- internal physical-hardware / USB testing on tested hardware
- AppArmor availability
- nftables availability
- curated cybersecurity tool-index review

The internal tool-index audit covered **44 indexed cybersecurity entries** and completed without a tool-index miss/warn in that validation run.

## Hardware note

Physical-hardware testing applies to the specific hardware tested. It is not a universal hardware certification. Compatibility can vary by firmware, Wi‑Fi adapter, graphics hardware, audio device, storage controller and power-management implementation.

## Upstream attribution

T‑PHANTOM OS is developed on top of Linux and uses upstream components from the Debian/Kali and KDE ecosystems. The project does not claim authorship over Linux, Debian, Kali Linux, KDE Plasma, or third-party security tools. T‑PHANTOM-specific work covers distribution engineering, build and integration, product identity, bilingual UX, workflow organization, validation, documentation, and project-created components.

See [`NOTICE.md`](NOTICE.md) for third-party licensing and attribution guidance.

## Original T‑PHANTOM tools

Project-specific cybersecurity tools designed and programmed for T‑PHANTOM are being introduced progressively after testing and stability validation. A private or development tool should not be treated as included in the public 5.3 release unless it is explicitly documented as released.
