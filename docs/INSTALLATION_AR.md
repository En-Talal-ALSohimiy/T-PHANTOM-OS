# دليل تثبيت T‑PHANTOM OS

هذا الدليل مخصص لتثبيت **T‑PHANTOM OS** كنظام أساسي على جهاز مخصص له.

> **تحذير:** اختيار استخدام القرص كاملًا أثناء التثبيت قد يؤدي إلى حذف جميع الأقسام والملفات وأنظمة التشغيل الموجودة على القرص المحدد.

## قبل البدء

- خذ نسخة احتياطية من جميع ملفاتك المهمة.
- تحقق من بصمة SHA‑256 لملف `T-PHANTOM.iso` ومقارنتها بملف `SHA256SUMS`.
- استخدم فلاشة بسعة كافية لملف ISO.
- على الأجهزة الحديثة يفضل الإقلاع بوضع **UEFI**.
- إذا منع Secure Boot الإقلاع، عطّله مؤقتًا من إعدادات Firmware ما لم يكن الإصدار مزودًا بسلسلة إقلاع موقعة.

## إنشاء فلاشة التثبيت من لينكس

أولًا حدد اسم الفلاشة بدقة:

```bash
lsblk -o NAME,SIZE,MODEL,TRAN,MOUNTPOINTS
```

بعد التأكد من اسمها، افصل أقسامها المركبة، مع استبدال `/dev/sdX` باسم الفلاشة الحقيقي:

```bash
sudo umount /dev/sdX* 2>/dev/null || true
```

اكتب الـISO على **الجهاز كاملًا** وليس على قسم مثل `sdX1`:

```bash
sudo dd if=T-PHANTOM.iso of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

## الإقلاع من الفلاشة

1. أعد تشغيل الجهاز.
2. افتح قائمة Boot Menu.
3. اختر الفلاشة، ويفضل خيار **UEFI USB**.
4. من شاشة T‑PHANTOM اختر **Start installer**.

## خطوات المثبت

يمر المثبت عادة بالمراحل التالية:

1. اختيار اللغة.
2. الدولة والمنطقة.
3. تخطيط لوحة المفاتيح.
4. إعداد الشبكة.
5. اسم الجهاز، والاسم المقصود افتراضيًا هو `t-phantom`.
6. إنشاء المستخدم وكلمة المرور.
7. تقسيم القرص.
8. تثبيت النظام الأساسي.
9. تثبيت محمل الإقلاع.
10. إعادة التشغيل والدخول إلى النظام المثبت.

## التثبيت كنظام أساسي وحيد

إذا كان الجهاز مخصصًا بالكامل لـT‑PHANTOM، اختر خيار التقسيم الإرشادي الذي يستخدم القرص كاملًا. قبل تأكيد الكتابة على القرص، راجع **اسم القرص وسعته** بعناية شديدة.

إذا كان القرص يحتوي على ملفات أو Windows أو أي نظام تحتاجه، **لا تكمل** قبل أخذ نسخة احتياطية أو تحديد خطة تقسيم مناسبة.

## فحص أول تشغيل

بعد الدخول للنظام نفّذ:

```bash
cat /etc/os-release
hostnamectl
findmnt /
systemctl --failed
```

الهوية الظاهرة للمستخدم يجب أن تكون:

```text
T-PHANTOM OS
```

واسم الجهاز:

```text
t-phantom
```

وإذا كان فاحص النظام متاحًا:

```bash
tphantom-system-check
```

## الاختبار داخل QEMU/KVM

يفضل استخدام VirtIO للرسوميات بدل `std` VGA القديم عند الإمكان:

```bash
qemu-system-x86_64 \
  -enable-kvm \
  -cpu host \
  -machine q35 \
  -m 4096 \
  -smp 4 \
  -device virtio-vga \
  -display gtk,grab-on-hover=off,show-cursor=on \
  -cdrom T-PHANTOM.iso \
  -boot d
```

## ملاحظة اعتماد الإصدار

نجاح التثبيت في الجهاز الافتراضي لا يعني التوافق مع كل أجهزة السوق. قبل النشر الواسع يجب اختبار UEFI والتخزين وكرت الشاشة وWi‑Fi وEthernet والصوت وإعادة التشغيل والإيقاف على أجهزة فعلية ممثلة.
